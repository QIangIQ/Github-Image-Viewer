Privacy Policy

Last updated: 14 October 2026

GitHub Image Viewer is a browser extension that shows the images in a GitHub folder as thumbnails.

  • No data collection. The extension does not collect, transmit, sell or share any personal or usage data. It has no analytics and no servers.
  • Local settings only. Your grid settings (thumbnail size, images per row, show names, hide list) are saved with chrome.storage.local in your own browser.
  • Network requests. Thumbnails are loaded from github.com, the same way GitHub loads a file when you open it, using your existing GitHub session. No other site is contacted.
  • Permissions. storage to remember your settings, and access to https://github.com/* to add the grid to folder pages.

Questions: open an issue.
