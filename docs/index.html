Features

Small extension. Big difference.

It lives on github.com, stays out of the way, and remembers how you like your grid.

Thumbnail grid

Every image in the folder appears above GitHub's file list, lazy-loaded so big folders stay fast.

Adjustable size

Drag from 48 px icons to 512 px previews. Pixel art stays crisp.

Images per row

Pin an exact column count, or let the grid fit as many as your screen allows.

Full-size lightbox

Click any thumbnail to view it full screen with its dimensions. Arrow keys flip through the folder.

Private repos too

Uses your normal GitHub session. No token, no OAuth, no extra permissions.

Zero tracking

No analytics, no servers. It only stores your grid settings in your browser.

FAQ

Questions, answered.

How do I see image thumbnails in a GitHub repository?

Install GitHub Image Viewer, then open any folder on github.com. Every PNG, JPG, GIF, SVG, WebP, AVIF, BMP and ICO file in that folder appears as a thumbnail grid above the file list.

Does it work with private repositories?

Yes. Images load through your normal GitHub session, so anything you can open on github.com shows as a thumbnail. No token is needed.

Does the extension collect any data?

No. It has no analytics and no server. The only thing it stores is your grid settings, in your own browser.

Which browsers are supported?

Google Chrome, Microsoft Edge, Brave, Opera, Vivaldi and other Chromium-based browsers.

Does it handle folders with hundreds of images?

Yes. Thumbnails load lazily as you scroll. GitHub itself lists at most 1,000 files per folder, so that's the ceiling per page.

Can I still open the file page?

Ctrl-click or middle-click a thumbnail to open GitHub's file page in a new tab, or click the file name inside the lightbox.
